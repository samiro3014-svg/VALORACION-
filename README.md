# Valoración inicial · Carlos Forero

Formulario web de valoración inicial para clientes de Carlos Forero, preparador físico y nutricionista.

- Página pública: https://samiro3014-svg.github.io/VALORACION-/
- Evaluación profesional: agregar `#evaluacion` al final del enlace.
- Formulario nuevo (versión 2, en prueba): https://samiro3014-svg.github.io/VALORACION-/nuevo/

## Funcionamiento
- El cliente completa 6 pasos (datos, objetivo, salud, alimentación, actividad y autorizaciones) y envía el resumen por WhatsApp al 350 634 3112.
- Las respuestas se conservan en el navegador del cliente mientras completa el formulario.
- La evaluación profesional calcula IMC, índice cintura-talla, gasto energético y proyección a 12 semanas, y copia los datos para la plantilla del plan.
- Las evaluaciones se guardan en el navegador del dispositivo donde se realizan y se pueden descargar como archivo.

El repositorio no contiene datos de clientes.
